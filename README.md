## 🚀 如何部署到手机

应用是纯静态 PWA，**任选一种方式**托管后，手机浏览器打开即可安装：

### 方式一：GitHub Pages（推荐，免费）
1. 新建 GitHub 仓库，上传这 6 个文件
2. 仓库 Settings → Pages → 选择分支 → Save
3. 得到地址 `https://你的用户名.github.io/仓库名/index.html`
4. 手机浏览器打开该地址

### 方式二：本地/内网服务器
```bash
cd francais-app
python -m http.server 8080
```
局域网手机访问 `http://电脑IP:8080`（需同一 WiFi）。

### 方式三：任意静态托管平台
Netlify / Vercel / 阿里云OSS / 腾讯云COS 等，直接上传即可。

## 📱 安装到手机（PWA 添加到主屏幕）

1. 手机浏览器打开部署好的地址
2. **Chrome**：地址栏菜单 → 「添加到主屏幕」 / 「安装应用」
3. **Safari**：分享按钮 → 「添加到主屏幕」
4. 桌面出现应用图标，点击即可像 App 一样使用，**离线也能打开**

> 首次访问会弹出「安装到手机桌面」横幅，点「安装」即可。

## 🔊 语音朗读说明

应用使用浏览器内置的 **Web Speech API** 语音合成，**无需联网、无需安装插件**：
- 每个单词、短句、长句旁都有 🔊 按钮，点击即朗读
- 「全部朗读」可连续播放整节单词 / 短句 / 长句
- 文章页可「播放全文」
- 朗读语速默认为 0.85（偏慢，适合跟读）

> 提示：不同手机系统自带法语语音包效果不同；若点击无声，可在手机系统「语音/文字转语音」设置中安装法语语音包（如 Google TTS 法语）。

## 🔔 开启每日提醒

1. 打开应用 → 点击「🔔 开启每日提醒」
2. 授权浏览器通知权限
3. 每天 8:00 自动收到「新内容已准备好」提醒

> 说明：纯前端 PWA 的本地定时提醒在**应用打开时**生效；要实现「应用完全关闭时也能推送」，需接入 Web Push 服务器（如 FCM / OneSignal），可后续扩展。

## 🧠 打卡与推荐逻辑

- **首日**：自动推荐第 1 课（问候与自我介绍）
- **打卡成功** → 目标推进到下一课，次日推荐**新内容**
- **昨日未打卡** → 目标不变，次日**重复推荐同一课**
- **完成 6 节基础课** → 自动进入**短文阅读阶段**（文章难度 A1-A2，带逐句翻译）
- **今天已打卡** → 显示「打卡成功」完成态，防重复打卡
- 数据保存在手机本地（localStorage），关闭应用不丢失
